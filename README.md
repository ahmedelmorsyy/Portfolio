# Ahmed Elmorsy Portfolio

A professional developer portfolio website customized for Ahmed Elmorsy, a Full Stack Web Developer specialized in GIS Dashboards & Interactive Maps. The site features a warm-minimalist, editorial design system utilizing custom CSS, paper grain textures, and a live Leaflet interactive map.

## Overview

This portfolio is designed to showcase expertise in full-stack web development and geographic information systems (GIS). It combines semantic design elements, responsive layouts, data visualization cues, and functional maps into a single-page application.

## Features

- **Warm-Minimalist Editorial Theme**: Premium Cream/Ink mode design featuring soft paper-grain overlays, Fraunces serif typography, and terracotta and sage accents.
- **Interactive Map**: Real-time Leaflet map centered on Egypt with custom styling, dynamic theme tiles, and a pulsing location marker.
- **Responsive Layout**: Designed to look premium across all devices (desktop, tablet, and mobile).
- **Featured Projects**: Detailed cards showcasing specialized projects:
  - **EcoMap Analytics**: Environmental Monitoring GIS Dashboard.
  - **D-Glow Station**: Skincare Sales Analytics System.
  - **Football Academy Manager**: Sports Operational Management System.
  - **GIS Interactive Map Demo**: Leaflet Map GeoJSON visualizer.
- **Skills and Services**: Categorized capabilities with custom progress graphics and service listings.
- **Contact Channels**: Interactive contact form UI alongside direct access buttons (Email, WhatsApp, LinkedIn, GitHub).
- **Theme Customization**: Responsive dark/light theme toggle.

## Tech Stack

- **Layout System**: Vanilla CSS Grid & Flexbox
- **Map Engine**: [Leaflet JS](https://leafletjs.com/)
- **Build System**: [Vite](https://vitejs.dev/)
- **Styling & Fonts**: Vanilla CSS + Google Fonts (Fraunces, Inter) + Tabler Webfont Icons

## How to Run

1. **Install Dependencies**:
   ```bash
   npm install
   ```
   *(On restricted Windows systems, use `npm.cmd install`)*

2. **Start Dev Server**:
   ```bash
   npm run dev
   ```

3. **Build Production Assets**:
   ```bash
   npm run build
   ```
